# DEPRECATED — ego2xml (abandoned 2015 XML-content proposal)

This directory is an **abandoned 2015 proposal** (authored by Paul Mueller) to convert
Egoboo's `.txt` / convention-driven content files (objects, modules, save games, etc.)
into an XML format. It is a set of HTML/XML/CSS mockups, not working code.

The XML migration **never shipped**. The runtime is still `.txt` / convention-driven,
and nothing in the build or runtime references these files.

It is kept here under `doc/legacy/` **for historical reference only**.
